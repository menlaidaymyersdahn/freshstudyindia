## 🌟 Overview
**Myers Global Pathways** is a modern, high-performance WordPress theme tailored for international education consultancies, university placement agencies, and student advisory services.

Built and customized specifically for **Myers Global Pathways**, founded by **Menlaiday Myers Dahn** (B.Sc. in Computer Science, Shri Rawatpura Sarkar University, India), this theme features built-in admissions application workflows, an interactive **Student Status & Document Portal**, and a dedicated **Myers Group of Companies** ecosystem showcase.

---

## 🚀 Key Features Included

1. **Admissions Application System**:
   - Built-in dynamic application modal generating unique tracking codes (`MGP-2026-XXXX`).
   - Integrated with WordPress REST API (`/wp-json/mgp/v1/apply`) to store leads in a custom `mgp_application` post type.

2. **Student Portal & Document Vault**:
   - Real-time application tracking by reference number or email (`/wp-json/mgp/v1/track`).
   - Instant document uploader enabling students to submit high school WAEC certificates, university transcripts, or passports later.

3. **Founder Spotlight & Executive Profile**:
   - Comprehensive biography of **Menlaiday Myers Dahn**.
   - Highlights his digital media reach (Fresh Updates News with 600,000+ followers), filmmaking background (Classic Myers Filmwork), and 2026 Computer Science graduation in India.

4. **Myers Group of Companies Portfolio**:
   - Full ecosystem grid including Myers Global Pathways, Fresh Updates News, Myers FRESH Technologies, MyEdRives, Fresh Marketplace, and Classic Myers Filmwork.

5. **Study in India Course Explorer**:
   - Filterable catalog of Engineering, Medicine, Pharmacy, Nursing, BBA/MBA, and Aviation programs with estimated tuition costs and merit scholarship details.

6. **Official 9-Email Directory**:
   - Quick-contact routing for Admissions, Scholarships, Visas, Support, and General Inquiries.

7. **Floating WhatsApp Assistance**:
   - Direct click-to-chat integration with Liberia (+231 889425645) and India (+91 93478 69324) advisor numbers.

## 📦 How to Install this Theme in WordPress

### Method 1: WordPress Admin Upload (Recommended)
1. In your WordPress Admin Dashboard, navigate to **Appearance** → **Themes**.
2. Click the **Add New Theme** button at the top, then click **Upload Theme**.
3. Choose the `myers-global-pathways-theme.zip` file.
4. Click **Install Now**.
5. Once uploaded, click **Activate**.

### Method 2: Manual FTP / cPanel Upload
1. Extract `myers-global-pathways-theme.zip`.
2. Upload the `myers-global-pathways` folder to your server's `/wp-content/themes/` directory.
3. Go to **Appearance** → **Themes** in your WordPress dashboard and click **Activate**.

---

## ⚙️ Setting Up the Homepage
1. In WordPress Admin, go to **Pages** → **Add New**.
2. Create a page titled **"Home"** and publish it.
3. Go to **Settings** → **Reading**.
4. Set **"Your homepage displays"** to **"A static page"**.
5. Select **"Home"** as your Homepage.
6. Click **Save Changes**.
